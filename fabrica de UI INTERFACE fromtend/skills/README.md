# Skills de la fábrica de UI

Esta carpeta reúne **todas las skills propias del proyecto**, separadas de las carpetas de componentes de terceros
(Appsmith, Budibase, GrapesJS, Fluent-UI, Lowcoder, ToolJet, Tauri-2, Wails, etc.), que siguen en el nivel superior de
`fabrica de UI INTERFACE fromtend/`.

Los `SKILL.md` que vienen dentro de los repos de componentes de terceros (Appsmith, Budibase, Fluent-UI, docs de VS Code)
se dejan en su sitio a propósito: forman parte de esos repos y no son skills propias.

Inventario detallado (origen, commit upstream y licencia): [`skills/INVENTARIO-UI.md`](skills/INVENTARIO-UI.md).
Componentes que solo se enlazan (sin copia): [`skills/ENLACES-COMPONENTES.md`](skills/ENLACES-COMPONENTES.md).
